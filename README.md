# MyDay — твой день

Личный трекер дел, привычек, расходов и здоровья. Главное — понятный следующий шаг, без игровых оценок и давления.

## Каждый день

- Одно главное дело дня, быстрый ввод и редактирование из обзора.
- План на сегодня и завтра, список выполненного и отмена последнего действия.
- Перенос на завтра меняет день в плане; отдельно заданный срок сохраняется.
- Дело можно разбить на шаги и отмечать их в списке.
- Фокус-таймер на 25 минут: выбор задачи, пауза, продолжение, сброс и восстановление после перезагрузки. Уведомление о завершении показывается в открытом приложении.
- Привычки с историей за семь дней.
- Вечерние итоги: заметка, перенос выбранных дел и главное дело на завтра.
- «Здоровье» объединяет сон, питание, тренировки, форму и программу.

В «Ещё» находятся цели, бюджет, практические инструменты и настройки. Подробная статистика открывается после семи разных дней записей. Дублирующие обзоры, прогнозы, RPG и генератор последствий откладывания убраны из навигации. Существующие записи дополнительных разделов остаются в данных и резервных копиях.

## Оформление

Чёрно-серебристый интерфейс: строгая сетка, тонкие линии, широкая типографика и объёмная хромированная форма. На телефоне меню снизу, на компьютере — сверху. Светлая тема также доступна.

Форма создаётся WebGL без внешних библиотек и изображений, медленно поворачивается и реагирует на курсор. Вне экрана и в скрытой вкладке вращение останавливается. Без WebGL используется SVG-вариант. Сетчатая графика также векторная.

Переходы, отклик кнопок и эффекты выполнения следуют действиям пользователя. Эффекты можно отключить в «Ещё»; системное уменьшение движения имеет приоритет. При первом открытии хромированной версии включается тёмная тема, затем сохраняется выбор пользователя.

## Данные

Основное хранилище — `spend-v1` в браузере конкретного устройства. В разделе данных доступны JSON-копии и импорт. Копии включают ежедневные заметки, главное дело, планирование, шаги и настройку анимации. Ежедневные записи при импорте объединяются по дате и времени обновления.

Фото находятся отдельно в IndexedDB и не включаются в JSON-копию. Облачная синхронизация требует отдельного сервера Vercel и настроек из `.env.example`; GitHub Pages исполняет только клиентскую часть.

## Запуск и проверка

```sh
node preview.cjs
```

По умолчанию: http://127.0.0.1:4173. Порт задаётся переменной `PORT`.

Основная логика трекеров находится в `app/app.html`, ежедневный интерфейс — в `app/redesign.js`, базовое оформление — в `app/redesign.css`. Хромированная тема: `app/chrome.css`; объёмная форма: `app/chrome.js`; сетчатая графика: `assets/chrome-wave.svg`.

```sh
node tests/mobile.cjs
node tests/daily.cjs
node tests/chrome.cjs
```

Проверки требуют Playwright и Chromium/Chrome. Настройки и ограничения описаны в `tests/README.md`. Они используют отдельный профиль и тестовые записи, не обращаясь к опубликованному приложению.

## Установка на телефон

Адрес GitHub Pages: https://myt7ky.github.io/myday/

На iPhone: Safari → Поделиться → На экран «Домой». На Android: меню браузера → Установить приложение. Для первого открытия нужен интернет. Публикация GitHub Pages: ветка `main`, папка `/(root)`, серверная сборка не требуется.
