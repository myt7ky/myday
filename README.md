# Мой день — PWA

Это полноценная web-версия приложения для установки на iPhone через Safari.

## GitHub Pages

В **Settings → Pages** должно быть:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Адрес:

**https://myt7ky.github.io/myday/**

## iPhone

Откройте адрес в Safari → **Поделиться → На экран «Домой»**.

## Функционал

В PWA перенесена исходная функциональность приложения: покупки и анализ трат, недельный лимит, графики, дела и напоминания, тренировки и статистика, форма/вес, питание и база продуктов, CSV/JSON резервные копии, тема интерфейса и глобальный поиск.

Офлайн-кэш обслуживает основные части приложения через service worker.

### Ограничение

Claude-specific AI API и облачная синхронизация из исходного файла требуют отдельного backend/API в автономной web-версии. Локальные функции приложения работают на устройстве.
