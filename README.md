# Мой день — PWA

Репозиторий уже подготовлен для первого теста установки на iPhone.

## Что сделать в GitHub

Откройте **Settings → Pages**.

В разделе **Build and deployment** выберите:

- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** /(root)

Сохраните настройки.

Через некоторое время адрес будет:

**https://myt7ky.github.io/myday/**

## На iPhone

1. Откройте адрес в Safari.
2. Нажмите **Поделиться**.
3. Выберите **На экран «Домой»**.
4. Добавьте «Мой день».

После установки приложение открывается как отдельный web app.

### Что сейчас в тестовой версии

Есть рабочая PWA-оболочка, нижняя навигация, тёмная/светлая тема, покупки, задачи и вес с локальным сохранением на устройстве.

Это именно **первый этап установки**. Полный функционал Claude-версии (графики, зал, питание, ИИ, синхронизация и база) следующим этапом переносится в эту PWA-архитектуру, чтобы не ломать его снова.
