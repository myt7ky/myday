# MyApp — твой день

Личный трекер расходов, дел, тренировок, питания и сна. Новый обзор вдохновлён LEVEL UP: спокойные карточки, фиолетовый акцент, две темы и мобильная навигация.

## Что изменилось

- Главная показывает актуальные задачи, расходы текущего месяца и выполнение привычек.
- Привычки используют существующую историю и входят в JSON-копии приложения.
- Фокус-таймер на 25 минут: пауза, сброс, восстановление после перезагрузки. Завершение показывается при открытом приложении, фоновых push-уведомлений нет.
- Колесо и заставка убраны с главного экрана. История трекера сохранена в прежнем формате `spend-v1`.
- Две темы, крупные кнопки, меню внизу, поддержка уменьшения анимации.
- Офлайн-кэш включает приложение, новый дизайн и изображения. Ошибки ресурсов больше не подменяются HTML-страницей.

## Открыть на телефоне

Адрес после публикации: https://myt7ky.github.io/myday/
На iPhone: Safari → Поделиться → На экран «Домой».
На Android: меню браузера → Установить приложение / Добавить на главный экран.
Один раз откройте сайт с интернетом, затем он доступен офлайн.

Данные находятся в браузере конкретного устройства. Для переноса откройте «Ещё» → JSON-копия на старом устройстве и импортируйте файл на новом. Фото хранятся отдельно в IndexedDB и в JSON не включаются.

## Запуск и разработка

Установленный Node.js: `node preview.cjs`, затем http://127.0.0.1:4173.
Основная логика: `app/app.html`. Новый обзор: `app/redesign.js`. Дизайн: `app/redesign.css`.
Проверка `node check.cjs` требует Playwright и Edge; путь к Playwright в скрипте задаётся для текущего компьютера.

GitHub Pages: ветка main, папка /(root). Серверная сборка не требуется.
AI и облачная синхронизация требуют отдельного сервера Vercel и переменных из `.env.example`. GitHub Pages исполняет только клиентскую часть. Локальные функции и резервные копии работают без этих сервисов.
