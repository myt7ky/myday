# Размещение MyDay и синхронизация Shorts

Локальный предпросмотр не является постоянным интернет-адресом. Этот пакет готовит функцию синхронизации; реальное размещение и подключение хранилища выполняются в аккаунте владельца.

## Подготовка Vercel

1. Подключить репозиторий myt7ky/myday в Vercel. Для просмотра новых функций выбрать ветку codex/mobile-dashboard-improvements (изменения пока в draft PR).
2. Корень проекта — корень репозитория, Framework Preset — Other. Сборка не требуется, каталог статических файлов — корень проекта. Функции находятся в api/.
3. Подключить Upstash Redis и передать проекту серверные переменные KV_REST_API_URL и KV_REST_API_TOKEN. Если интеграция создаёт UPSTASH_REDIS_REST_URL/TOKEN, скопировать значения в соответствующие KV_REST_API_* переменные.
4. Разместить проект. Использовать один HTTPS-адрес на телефоне и ПК. Значения серверных переменных не должны попадать в app/, JSON-резервные копии или GitHub.
5. Открыть «Ещё → Синхронизация Shorts». Адрес по умолчанию: https://АДРЕС-ПРОЕКТА/api/notes-sync. На первом устройстве создать 64-символьный код; ввести тот же код на втором.
6. Нажать «Подключить и синхронизировать» на каждом устройстве. Код является секретом доступа к области заметок. Он не передаётся в URL.
7. Создать тестовую идею с референсом, проверить появление на другом устройстве, изменить текст, сменить этап и проверить удаление.

## Что синхронизируется

Только mydayNotes: тексты, этапы, сжатые референсы и отметки удаления. Финансы, здоровье, оформление и быстрый черновик не отправляются этим подключением. Старый общий механизм исключает заметки, чтобы два механизма не перезаписывали друг друга. Демо-режим не отправляет данные.

После подключения изменения ждут 1.8 секунды перед отправкой. Дополнительная проверка — при возвращении в приложение, появлении сети и раз в минуту, пока приложение открыто. Если приложение закрыто, фоновая отправка не обещается.

Сервер хранит JSON со своей ревизией. Запись выполняется через Redis EVAL с проверкой предыдущей ревизии. При 409 клиент повторно получает данные. Одновременные правки сохраняются дополнительными карточками «сохранённая версия». Удалённые карточки остаются в данных как tombstones, чтобы не воскреснуть на другом устройстве. Отключение на устройстве не удаляет облачные записи.

Код области превращается в SHA-256 для ключа Redis. Это разграничение доступа по секретному коду, не сквозное шифрование. Владелец Redis имеет доступ к содержимому. Утрата кода требует переноса в новую область через JSON-копию.

Тексты и картинки хранятся в Redis вместе с заметками. Предел снимка — 3 МБ UTF-8, не более 2000 записей, включая отметки удаления; до 3 картинок по 350000 символов data URL на карточку. Ненужные референсы можно удалить после выгрузки ZIP.

## Установка на телефон и офлайн

Открыть HTTPS-адрес один раз с сетью и дождаться полной загрузки. В студии есть «Установить на телефон», в «Ещё» — «Установка приложения». На iOS: Safari → Поделиться → На экран Домой. На Android: меню Chrome → Установить приложение.

Обычный HTTP-адрес домашней сети не обеспечивает установку и service worker на телефоне. localhost пригоден для локальной проверки на том же компьютере.

Ярлык «Поймать идею Shorts» открывает ?capture=shorts. Незаконченный быстрый черновик сохраняется на устройстве. Кэш содержит интерфейс и локальные материалы, но не запросы /api/. При смене версии старые кэши MyDay удаляются. Заметки сохраняются в localStorage и переживают перезапуск без сети. Если очистить данные браузера, локальные заметки и код подключения удалятся; сохраняйте JSON-копии.

## Проверки и пределы валидации

- tests/notes-api.cjs — серверный обработчик с имитацией Redis: код/область, Origin, 503, 409 и проверка данных.
- tests/notes-sync.cjs — два браузерных устройства с имитацией API: референсы, правки, конфликтующие версии, удаления, повтор CAS, правки во время отправки, очередь после перезапуска, отключение и демо-изоляция.
- tests/shorts.cjs — черновик, доска, drag/drop, выбор этапа на телефоне, ZIP, подсказки установки, ярлык, обе темы и ширины 320–1440.
- tests/shorts-offline.cjs — настоящий локальный HTTP + service worker, затем отключённая сеть и перезапуск.
- Архив ZIP также проверен стандартным .NET ZipArchive.
- Живые Vercel/Redis, браузеры на физических iOS/Android и установка на реальном устройстве не проверены: аккаунт хостинга ещё не подключён.

Документация инфраструктуры: https://upstash.com/docs/redis/features/restapi и https://redis.io/docs/latest/commands/eval/.
